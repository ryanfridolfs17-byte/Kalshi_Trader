============================================================
  KALSHI TRADING BOT - SETUP GUIDE FOR BEGINNERS
============================================================

Kalshi is a CFTC-regulated prediction market that's fully
live in the U.S. Unlike Polymarket, there's no waitlist.

============================================================
  STEP 1: CREATE YOUR KALSHI ACCOUNT
============================================================

  1. Go to https://kalshi.com
  2. Click "Sign Up"
  3. Enter your email and create a password
  4. Complete identity verification (required by law):
     - Name, date of birth
     - Government-issued ID
  5. Once verified, you're ready to go!

  WHY KALSHI IS GREAT FOR BEGINNERS:
  - Fully regulated (CFTC-approved) - your funds are protected
  - Available in most U.S. states right now
  - Has a FREE DEMO environment for practice
  - Supports debit card, bank transfer, and crypto deposits
  - Sports, weather, economics, and world event markets


============================================================
  STEP 2: FUND YOUR ACCOUNT
============================================================

  You have several options:

  BANK TRANSFER (ACH) - Recommended, FREE:
  - Go to your Kalshi account > Deposits
  - Connect your bank via Aeropay
  - Transfer $15-20
  - Takes 1-3 business days

  DEBIT CARD - Fastest, 2% fee:
  - Instant deposit
  - 2% fee ($20 deposit = $0.40 fee)
  - Fine for small proof-of-concept amounts

  Note: For demo/practice mode, you don't need to deposit
  anything! Kalshi gives you fake money to practice with.


============================================================
  STEP 3: GET YOUR API KEY
============================================================

  1. Log into Kalshi at kalshi.com
  2. Click your profile icon > Account Settings
  3. Scroll to "API Keys"
  4. Click "Create New API Key"
  5. You'll receive:
     - KEY ID (a string like "a952bcbe-ec3b-...")
     - PRIVATE KEY (an RSA key - starts with "-----BEGIN RSA
       PRIVATE KEY-----")

  IMPORTANT:
  - Save the private key IMMEDIATELY - you can't see it again
  - Save it as a file called "kalshi_private_key.pem"
  - Put this file in the same folder as the bot
  - NEVER share this key with anyone


============================================================
  STEP 4: INSTALL PYTHON & PACKAGES
============================================================

  INSTALL PYTHON:
  1. Go to https://www.python.org/downloads/
  2. Download and install (check "Add Python to PATH")

  INSTALL PACKAGES:
  Open Terminal (Mac) or Command Prompt (Windows) and type:

    pip install requests
    pip install cryptography

  (If "pip" doesn't work, try "pip3")


============================================================
  STEP 5: SET UP THE BOT FILES
============================================================

  Put ALL these files in one folder:

    kalshi_bot.py         <- Main bot (you run this)
    config.py             <- Your settings (you edit this)
    kalshi_client.py      <- Talks to Kalshi's API
    risk_manager.py       <- Safety controls
    market_scanner.py     <- Finds markets
    strategy.py           <- Trading brain
    kalshi_private_key.pem <- Your API key file
    setup_guide.txt       <- This file

  Then edit config.py:
  1. Replace "YOUR_API_KEY_ID_HERE" with your Key ID
  2. Make sure PRIVATE_KEY_PATH = "kalshi_private_key.pem"
  3. Leave ENVIRONMENT = "demo" (we'll start with practice)
  4. Leave DRY_RUN = True (extra safety layer)


============================================================
  STEP 6: YOUR PROGRESSION PATH
============================================================

  LEVEL 1 - DRY RUN + DEMO (start here):
  ----------------------------------------
    config.py settings:
      ENVIRONMENT = "demo"
      DRY_RUN = True

    What happens: Bot scans real Kalshi markets, analyzes
    them, and tells you what it WOULD do. No trades placed.
    Run for a few days to see if you like its decisions.

    Run: python kalshi_bot.py

  LEVEL 2 - DEMO MODE (practice trading):
  ----------------------------------------
    config.py settings:
      ENVIRONMENT = "demo"
      DRY_RUN = False

    What happens: Bot places REAL orders on Kalshi's demo
    server with FAKE money. Perfect for testing that the
    mechanics work before risking real dollars.

    The demo API URL is: https://demo-api.kalshi.co

  LEVEL 3 - PRODUCTION (real money):
  -----------------------------------
    config.py settings:
      ENVIRONMENT = "production"
      DRY_RUN = False

    What happens: Bot trades with your REAL money.
    Only do this after you've:
      - Watched dry runs for several days
      - Practiced in demo mode
      - Funded your account
      - Reviewed the trade log and liked the results


============================================================

============================================================

  2. Navigate to your bot folder:

============================================================
  UNDERSTANDING KALSHI CONTRACTS
============================================================

  Every contract on Kalshi works like this:

  - You buy YES or NO contracts priced 1¢ to 99¢
  - The price = what the market thinks the probability is
  - If you're RIGHT: each contract pays out $1.00 (100¢)
  - If you're WRONG: your contract is worth $0

  EXAMPLE:
  "Will the Super Bowl have over 50 points?" YES at 45¢

  Buy 5 YES contracts: Cost = 5 × 45¢ = $2.25
  If over 50 points:   Payout = 5 × $1.00 = $5.00 (profit: $2.75)
  If under 50 points:  Payout = $0.00 (loss: $2.25)

  FEES:
  - Trading fees: Max 2¢ per contract (built into the price)
  - ACH deposit/withdrawal: FREE
  - Debit card: 2% fee
  - No fee on settled contracts


============================================================
  TROUBLESHOOTING
============================================================

  "ModuleNotFoundError: No module named 'cryptography'"
  → Run: pip install cryptography

  "ModuleNotFoundError: No module named 'requests'"
  → Run: pip install requests

  "Private key file not found"
  → Make sure kalshi_private_key.pem is in the same folder
  → Check the filename matches PRIVATE_KEY_PATH in config.py

  "API Error 401 Unauthorized"
  → Your API key might be wrong or expired
  → Generate a new one in Kalshi account settings

  "Exchange is currently closed"
  → Kalshi has maintenance windows (Thursdays 3-5am ET)
  → The bot will automatically retry next cycle

  "No qualifying markets found"
  → Normal sometimes! The bot is selective.
  → Try lowering MIN_VOLUME in config.py


============================================================
  KALSHI vs POLYMARKET - KEY DIFFERENCES
============================================================

  KALSHI:
  + Fully regulated (CFTC), live in most U.S. states
  + No crypto wallet needed - use debit card or bank
  + Free demo environment for practice
  + Contracts priced in cents ($0.01 - $0.99)
  + No waitlist - sign up and start today
  - Slightly smaller market selection than Polymarket
  - Trading fees on each contract

  POLYMARKET:
  + Larger market catalog, more obscure topics
  + Lower/no trading fees
  + Crypto-native (USDC on Polygon)
  - U.S. access still on waitlist (Feb 2026)
  - Requires crypto knowledge
  - Less regulatory protection
